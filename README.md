# Richard Olivares — Senior Product Designer Portfolio

A responsive, accessible, English-language portfolio showcasing senior product design work across fintech, mobility, hospitality, and interface design.

## Local preview

This is a buildless static site. From the repository root, start any static HTTP server and open `index.html` through it.

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — portfolio home
- `global66.html`, `chek.html`, `cobroqr.html`, `mesero.html`, `rocketaxi.html` — case studies
- `ui-concept.html` — interface explorations
- `css/style.css` — shared design system and responsive layout
- `js/site.js` — mobile navigation and small progressive enhancements
- `img/optimized/` — lightweight card and portrait assets
